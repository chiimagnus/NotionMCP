# NotionMCP

[English](./README.en.md) | 中文

把电脑暴露成一个mcp服务，供Notion AI（后续会支持ChatGPT吧？）使用，提供下面这五个工具：

- `read_rules` —— 读取项目规则和所有可用技能清单
- `read_file` —— 读取文本文件内容
- `read_image` —— 读取图片文件
- `run_command` —— 执行 shell 命令
- `apply_patch` —— 新建、修改或删除文件
