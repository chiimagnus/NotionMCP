# NotionMCP

[中文](./README.md) | English

Turns your computer into an MCP server for Notion AI (ChatGPT support may come later?), providing these five tools:

- `read_rules` — Read project rules and the list of available skills
- `read_file` — Read text file contents
- `read_image` — Read image files
- `run_command` — Execute shell commands
- `apply_patch` — Create, modify, or delete files
